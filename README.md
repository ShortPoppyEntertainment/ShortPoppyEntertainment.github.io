# My Website

A simple one-page website hosted free with GitHub Pages.

## Files

| File | What it does |
| --- | --- |
| `index.html` | The page content (text, photo) |
| `style.css` | Colours, fonts and layout |
| `images/photo.jpg` | **Your photo** (upload this) |
| `images/placeholder.svg` | Shown until `photo.jpg` exists |

## Put it online (all on an iPad)

1. In Safari, sign in at github.com and tap **+** > **New repository**.
2. Name it. For a personal site named `yourusername.github.io`, use exactly that. Any other name also works.
3. Set it to **Public** and create it.
4. Tap **uploading an existing file**, then upload `index.html`, `style.css`, `.nojekyll` and the `images` folder from the Files app. Tap **Commit changes**.
5. Go to **Settings > Pages**. Under **Build and deployment**, set **Source** to **Deploy from a branch**, choose **main** and **/ (root)**, then **Save**.
6. After a minute or two the site appears at `https://yourusername.github.io/repository-name/`.

## Add your photo

1. Open the repository, then open the `images` folder.
2. Tap **Add file > Upload files** and choose your picture from Photos or Files.
3. Name it `photo.jpg` (the same name as in `index.html`). To replace an existing photo, upload a file with the same name.
4. Tap **Commit changes**. The page updates after a minute.

Tip: photos from an iPad can be very large. Resize to around 1600 pixels wide before uploading so the page loads quickly. If your photo is a `.png` or `.heic`, either convert it to JPG or change `photo.jpg` in `index.html` to match the file name. HEIC images do not show in all browsers, so JPG is safest.

## Edit text on the iPad

1. Open the file on github.com and tap the **pencil** icon.
2. Make your changes and tap **Commit changes**.

Alternatively, press the `.` key (with a keyboard) on the repository page to open github.dev, a full editor in Safari. Apps like Working Copy also let you edit and push from the iPad.
